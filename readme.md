# 📝 Full Stack Notes App using MERN

A modern and responsive Full Stack Notes Application built using the **MERN Stack** — MongoDB, Express.js, React.js, and Node.js.

This application allows users to securely create accounts, log in, manage notes, pin important notes, search through notes, and much more.


## 🚀 Features

### 🔐 Authentication
- User Sign Up
- User Login
- JWT Authentication
- Protected Routes

### 📝 Notes Management
- Add Notes
- Edit Notes
- Delete Notes
- View All Notes
- Pin Important Notes

### 🔍 Search Functionality
- Search notes by title or content

### 🎨 UI Features
- Responsive UI with Tailwind CSS
- Toast Notifications
- Empty State Screens
- Modal Popup for Add/Edit Notes
